# Leashis 2.0.0 검증 기록

검증 날짜: 2026-10-14 (Asia/Seoul). 버전 범위의 상한은 조사 시점의 정식 Minecraft 26.3입니다. 스냅샷은 배포 대상에서 제외합니다.

## 빌드 검증

Fabric 24개, NeoForge 22개, Bukkit 공통 1개로 총 47개 배포 JAR을 생성했습니다.
각 모드 JAR은 해당 Minecraft와 고정된 로더/API 버전으로 별도로 컴파일합니다.

통합 검사는 localhost 격리 서버에 커스텀 모드 없는 프로토콜 클라이언트 두 개를 접속시켜 수행합니다.

- 생존 목줄 소비, 구체적/일반 상호작용 중복 패킷에서 중복 소비 방지.
- 바닐라 거북이 생성 및 목줄 보유자 패킷 전달.
- 수동 해제와 목줄 하나만 반환, 크리에이티브 연결의 소비·반환 없음.
- 당김 속도 패킷과 최대 거리 초과 시 해제.
- 울타리 연결, 묶인 플레이어의 매듭 우클릭·공격 보호, 보호 해제 후 매듭 제거.
- 묶인 플레이어의 명령 기반 차원 이동 차단, 보유자 로그아웃 정리.
- Bukkit 계열의 `/leashis reload`, 바닐라 고정 범위를 넘는 사용자 설정 거리 유지 및 설정 거리 초과 시 해제.

코어 회귀 검사는 사망·관전·탑승·차원 불일치·비활성화·여러 대상 정리, 반환 소유권과 게임 모드 변경, 설정 범위 보정, 유한하고 제한된 당김 속도를 검사합니다.
NeoForge GameTest는 실제 Minecraft 엔티티로 연결·해제·반환·울타리·저장 차단·차원 이동 및 반복 종료 처리를 검사합니다.

## 검증의 범위와 남은 수동 확인

전 버전의 빌드 성공과 대표 버전의 기능 실행을 구분합니다. 모든 패치 버전에서 전체 게임 플레이를 반복 실행한 것은 아닙니다.
현재 통합 검사 라이브러리의 26.3 프로토콜 지원이 없어 최신 버전은 기동과 종료, 컴파일을 검증했습니다.
NeoForge 1.21.1 검사 중 프로토콜 라이브러리가 바닐라 외 레시피 데이터에 대해 파싱 경고를 출력했지만, 접속과 위 기능의 독립된 검사는 모두 통과했습니다.

실제 렌더링 화면은 자동 프로토콜 검사의 범위 밖입니다. 배포 전 두 실제 바닐라 클라이언트에서 줄 위치·움직임과 포털 진입 화면을 확인하는 것이 남아 있습니다.
다른 플러그인의 텔레포트·엔티티 관리·목줄 이벤트 개입에 대한 조합 검사는 수행하지 않았습니다.
서버 강제 종료 시 아이템 반환은 보장하지 않으며, 정상 종료와 보유자 로그아웃에서는 반환 및 프록시 정리를 수행합니다. 묶인 플레이어의 로그아웃은 프록시만 제거하고 연결 정보를 보관하며, 같은 서버 실행 중 재접속하면 플레이어 또는 울타리 보유자에 다시 연결합니다. 서버 재시작 시 연결 정보는 유지하지 않습니다.

## 재현

README의 빌드·검증 명령을 사용합니다. `tools/smoke_server.py`는 개발 실행 디렉터리에 EULA 동의 파일과 localhost 테스트 서버 설정을 생성합니다.
운영 월드는 검사에 사용하지 않습니다. Bukkit 계열 검사는 별도로 준비한 서버 JAR 경로를 `--paper-dir`에 지정합니다.
CI는 동일한 버전표를 사용해 전체 빌드, 코어 검사, NeoForge GameTest, Fabric 프로토콜 통합 검사를 실행합니다.

## 2026-10-15 재접속 수정 검증

- 코어 회귀 검사 통과: 대상 로그아웃 동안 연결 보관, 재접속 복구, 울타리 보유자 유지, 크리에이티브 반환 없음, 복구 실패·보유자 종료·비활성화·서버 종료 시 단일 반환.
- Bukkit 빌드 및 Fabric·NeoForge 1.21.1 컴파일 통과.
- Fabric 1.20.1 및 NeoForge 1.21.1 실제 서버의 프로토콜 통합 검사 통과: 플레이어와 울타리 연결 각각 재접속 복구, 추가 목줄 소비·반환 없음, 보유자 로그아웃 정리.
- NeoForge 검사에서는 기존 레시피 데이터 파싱 경고가 재현되었으며 기능 검사는 모두 통과했습니다. 이번 수정의 Bukkit 재접속은 실제 서버에서 별도 실행하지 않았습니다.

재접속 정책 명령어 추가 검증: `/leashis reconnect true|false` 전환에 따른 실제 재접속 유지·해제 및 단일 반환을 Fabric 1.20.1과 NeoForge 1.21.1 통합 검사로 확인했습니다. 두 서버의 설정 파일에 `keepOnLogout=false`가 저장된 것도 확인했습니다. 코어 회귀 검사, Bukkit 빌드, Fabric·NeoForge 1.21.1 빌드 및 26.3 컴파일이 통과했습니다.

울타리 블록 보호 추가: 묶인 대상 자신의 현재 매듭이 위치한 울타리만 파괴를 차단하며, `allowLeashedRemoveFenceKnot` 설정과 무관하게 적용합니다. Bukkit 빌드와 Fabric·NeoForge 1.21.1 빌드 및 26.3 컴파일을 통과했습니다. NeoForge GameTest 13개에서 생존·크리에이티브 차단, 다른 플레이어 허용 및 연결 해제 후 보호 종료를 확인했습니다. NeoForge 26.1.2 이후 변경된 블록 파괴 이벤트는 버전별 소스 변환으로 대응하며 취소 시 바닐라 클라이언트에 블록 상태를 다시 전달합니다.

Fabric 1.20.1 및 NeoForge 1.21.1 실제 서버 통합 검사에서도 크리에이티브 상태에서 자기 울타리 파괴 차단, 다른 울타리 파괴 허용, 해제 후 이전 울타리 파괴 허용과 기존 재접속 회귀 검사가 모두 통과했습니다.

NeoForge 1.21.1 호환성 수정: 빌드 기준과 메타데이터 최소 버전을 21.1.259에서 21.1.257로 맞췄습니다. 21.1.257 대상 2.0.1 JAR 빌드, 코어 회귀 검사, GameTest 13개 및 격리 서버의 전체 프로토콜 통합 검사를 통과했습니다. JAR의 의존성 범위 `[21.1.257,)`와 테스트 클래스 제외를 확인했습니다. Create 등 운영 서버의 다른 모드와 조합한 실행은 이번 검사의 범위에 포함하지 않았습니다.

피스톤 보호 추가: 연결된 플레이어가 있는 울타리는 피스톤 구조 해석 단계에서 이동을 거부합니다. 밀기·끈끈이 당기기 및 슬라임/꿀 구조의 전체 이동 목록을 검사하며, 로그아웃 보관 중인 연결도 포함합니다. Bukkit은 확장·수축 이벤트의 이동 블록 목록을 검사합니다. 코어 회귀 검사와 세 플랫폼 1.21.1 JAR 빌드, Fabric·NeoForge 26.3 컴파일을 통과했습니다. Fabric 1.20.1과 NeoForge 1.21.1 (21.1.257) 실제 서버 통합 검사에서 직접 밀기, 슬라임 경유 밀기, 끈끈이 당기기, 대상 오프라인 시 보호, 해제 후 이동 허용 및 기존 기능 회귀 검사가 통과했습니다. 두 모드 JAR의 Mixin 클래스·설정 포함과 로더 등록, NeoForge 최소 버전 21.1.257 유지도 확인했습니다. Bukkit의 피스톤 동작 및 Create 기계식 피스톤/컨트랩션과의 조합은 이번 실제 서버 검사의 범위 밖입니다.

울타리 사망·부활 연결 유지 추가: 울타리 연결을 사망 대기 상태로 보관하고, 부활 시 기존 매듭 근처의 위치를 찾아 새 플레이어 객체에 연결을 복구합니다. 실제 침대·리스폰 앵커·저장 스폰은 변경하지 않습니다. 모드는 네트워크 플레이어 교체가 완료되는 다음 서버 틱에 복구하고, Bukkit은 부활 위치 이벤트와 다음 틱 복구를 사용합니다. 내부 부활 이동만 차원 이동 제한에서 예외 처리합니다. 울타리가 사라지면 보관 연결을 해제하고 기본 스폰을 사용합니다.

코어 회귀 검사에서 사망 대기·재접속 설정 독립성·반복 이벤트·단일 반환·보유자 사망 정리·매듭 소멸을 검증했습니다. 세 플랫폼 1.21.1 대상 2.0.2 JAR 빌드 및 Fabric·NeoForge 26.3 컴파일이 통과했습니다. Fabric 1.20.1과 NeoForge 1.21.1 (21.1.257) 실제 서버에서 동일 차원 및 다른 차원의 스폰을 지정한 뒤 울타리 근처 부활·같은 매듭 복구·추가 목줄 소비/반환 없음·해제 후 원래 스폰 복귀와 전체 기존 기능 회귀 검사가 통과했습니다. Bukkit의 부활 기능은 이번 실제 서버 검사에서 별도 실행하지 않았습니다.

사망 유지 설정 추가: 공통 `keepOnDeath` 기본값은 true이며 `/leashis death [true|false]` 관리자 명령어로 조회·변경·저장할 수 있습니다. false이면 울타리에 묶인 대상도 사망 시 연결 해제·단일 목줄 반환·기존 저장 스폰 부활을 사용합니다. 사망 대기 중 false로 변경하면 보관 연결을 해제하며, 이미 예약된 부활 이동도 수행하지 않습니다. 코어 회귀 검사와 세 플랫폼 2.0.2 JAR 빌드 및 Fabric·NeoForge 26.3 컴파일이 통과했습니다. Fabric 1.20.1과 NeoForge 1.21.1 (21.1.257) 실제 서버 통합 검사에서 true/false 정책, 원래 스폰, 반환 소유권 및 기존 기능 회귀 검사가 모두 통과했고, 두 설정 파일에 `keepOnDeath=false`가 저장됨을 확인했습니다.

프록시 히트박스 축소: 목줄 표시 엔티티를 투명 아기 거북이에서 투명 아기 토끼로 교체했습니다. Bukkit은 나이를 고정해 성장에 따른 히트박스 확대를 막습니다. 코어 검사 및 세 플랫폼 2.0.3 JAR 빌드, Fabric·NeoForge 26.3 컴파일을 통과했습니다. NeoForge 1.21.1 GameTest 13개에서 바닐라 토끼 타입·아기 상태·폭 0.2/높이 0.25블록의 히트박스와 기존 기능을 확인했습니다. 초기 GameTest 실행은 테스트 검색 결과가 비어 실행되지 않았고, 생성·컴파일·실행 준비 작업을 다시 수행한 실행에서 13개 모두 통과했습니다. Fabric 1.20.1 및 NeoForge 1.21.1 (21.1.257) 프로토콜 통합 검사에서도 토끼 생성·목줄 패킷, 반환, 울타리, 피스톤, 사망·부활, 재접속 및 정책 변경 회귀 검사가 전부 통과했습니다. Bukkit 동작은 이번 실제 서버 검사에서 별도 실행하지 않았습니다.

수동 당기기 추가: `/l` 및 `/leashis pull`은 현재 직접 잡고 있는 플레이어들을 시선과 무관한 목줄 방향으로 당기며 약 1블록 앞에서 감속·제동합니다. 최대 3초 동안 적용되고 두 명령어는 1초 쿨다운을 공유합니다. 일반 플레이어에게 허용하되 기존 설정 명령어의 관리자 권한은 각 하위 명령어에서 유지했습니다. Bukkit은 `leashis.pull`을 기본 허용합니다. 코어 회귀 검사에서 방향 벡터·속도 상한·도착/제동·다중 대상·울타리 전환·시간 제한·재접속 취소를 검증했습니다. 세 플랫폼 2.0.4 JAR 빌드와 Fabric·NeoForge 26.3 컴파일을 통과했습니다. Fabric 1.20.1 및 NeoForge 1.21.1 (21.1.257) 실제 서버의 비OP 클라이언트가 두 명령어를 사용하고, 쿨다운·기본 느슨한 거리 안에서의 당김 속도 패킷·관리자 명령어 보호·울타리 대상 제외 및 전체 기존 기능 회귀 검사를 통과했습니다. 실제 클라이언트의 도착 움직임/벽 충돌 렌더링과 Bukkit 실행은 이번 프로토콜 검사의 범위 밖입니다.

매듭 투사체 보호 추가: 플레이어가 연결된 매듭은 화살 등 투사체의 직접 피해를 거부합니다. 접속 중인 대상뿐 아니라 오프라인·부활 대기 보관 연결도 포함하고, 발사자나 매듭 직접 제거 허용 설정과 무관하게 적용합니다. 일반 우클릭 해제 및 비어 있는 매듭의 바닐라 피해 처리는 유지합니다. 공통 Mixin은 구버전 HangingEntity.hurt, 1.21 BlockAttachedEntity.hurt, 1.21.2 이후 hurtServer를 각각 처리합니다. Bukkit은 투사체 명중·엔티티 피해·매듭 제거 이벤트를 보호합니다.

코어 검사와 세 플랫폼 2.0.4 JAR 빌드, Fabric·NeoForge 26.3 컴파일이 통과했습니다. NeoForge 1.21.1 GameTest 14개에서 보유자 화살, 오프라인·부활 대기, 직접 공격 필터, 해제 후 정상 피해를 확인했습니다. Fabric 1.20.1 및 NeoForge 1.21.1 (21.1.257) 실제 서버에서 날아오는 화살로 활성·오프라인 매듭이 유지되고, 동일한 궤적의 화살로 비어 있는 매듭은 제거되는 대조 검사를 포함해 전체 회귀 검사가 통과했습니다. 두 모드 JAR의 Mixin 클래스·설정 포함 및 등록도 확인했습니다. Bukkit 투사체 동작은 이번 실제 서버 검사에서 별도 실행하지 않았습니다.
